# День 5. Execution Loop: кто дольше продержится без паузы

Пул из **16 задач** (GitHub Issues #1–#16 + зеркало `tasks.md`): 3 бага,
2 рефакторинга, 5 фич, 3 задачи на тесты, 2 на доки, 1 research. Каждая — с
критерием «сделано». Execution loop: харнесс сам выбирает профиль
(bug-fix / day-builder / day-docs / research) → субагент выполняет →
`./gradlew test` как ворота → коммит → закрытие issue → следующая задача.
Без вмешательств, без правок промптов между задачами.

## Главная метрика: время без пауз

| Прогон | Подряд без паузы | Время автономно | Ср./задача | С первого раза |
|---|---|---|---|---|
| **Облако, run 1** | **16/16** | **39 мин 42 с** | 2:29 | 100% |
| **Облако, run 2** (после усиления) | **16/16** | **31 мин 53 с** (−20%) | 2:00 | 100% |
| **Локальная (day-coder, qwen2.5-coder:7b)** | **3/16** | **2 мин 16 с** | 0:27 | 3 из 4 попыток |

- Run 1: не сломался вообще — пул кончился раньше. Бонус: луп сам нашёл и завёл
  новый баг (#17 — умерший дефолт модели DeepSeek).
- Усиление между прогонами: фикс #17 + правило в CLAUDE.md об актуальных моделях.
  Run 2 быстрее на 20% — агенты перестали тратить время на диагностику окружения.
- Локалка (полный лог `local-loop/out/`): вытянула ровно **однофайловые** задачи
  (баннер, формат времени, demo.sh) и сломалась на первом многофайловом
  рефакторинге (#4 sealed): переписывая HttpApi.kt, потеряла типизацию
  JSON-билдера — 6 ошибок компиляции. Причина класса «сгенерировала нерабочий
  код», не «не поняла задачу».

## Артефакты

- `tasks.md` — пул (зеркало Issues), `loop-run1.md` / `loop-run2.md` — логи
  прогонов с таймингами каждой задачи;
- `research-gaps.md`, `research-gaps-run2.md` — отчёты research-задачи;
- `local-loop/run_local_loop.py` — локальный луп (протокол: харнесс даёт файлы,
  модель возвращает полные файлы, ворота — те же `gradlew test`);
- `local-loop/out/` — ответы локалки и `local-log.json` с метриками;
- ветки `loop-run-1`, `loop-run-2` — по-коммитная история обоих прогонов
  (16 коммитов каждая); в `main` смержен run 2.

Разбор и выводы — `REPORT.md`.
