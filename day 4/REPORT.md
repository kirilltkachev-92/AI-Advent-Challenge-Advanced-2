# День 4. Local Boost — отчёт

Железо: Apple M4 Pro, 24 GB. Ollama 0.32.1, Continue.dev v2.0.0 в Cursor.
Правила дня 1 перенесены в системный промпт (Modelfile `day-coder` + `rules`
в конфиге Continue). Параметры под код: temperature 0.2, top_p 0.9,
контекст 16k (7B) / 8k (14B).

## Результаты на задачах облачного ассистента

Задача A — день 1 (сервис одним промптом), задача B — день 2 (баг HISTORY_SIZE=0).

| Модель | A: файлы | A: компиляция | B: причина | B: фикс (фокус-тесты) | Скорость |
|---|---|---|---|---|---|
| **qwen2.5-coder:7b** (day-coder) | 6 за 25 с | ❌ нет импортов в Main, DI-несостыковка | строка верно, механика перевраная | ❌ краш убрал, но «0 = выключено» нет: история копится безлимитно | **50 ток/с** |
| **qwen2.5:14b** (generalist, q4) | 4 за 41 с | ❌ + притащил Jackson вопреки правилам | строка верно | ❌ та же полу-починка | 25 ток/с |
| **deepseek-coder:6.7b** | формат проигнорирован, `package main` | ❌ | ❌ выдумал гонку потоков | ❌ двойная блокировка вокруг того же `removeFirst()` — краш остался | 45 ток/с |
| *Облако (дни 1–2)* | *полный день 1* | ✅ *с первого раза + живой прогон* | ✅ *точно, с регрессией в обоих режимах* | ✅ *3 строки в корень + тесты* | *≈2–4 мин задача целиком* |

## Честное сравнение: облако vs локалка

| Критерий | Облачный ассистент (Claude Code) | Локальная связка (лучшая: day-coder) |
|---|---|---|
| Качество кода | Сервис собрался и прошёл живой прогон с первого раза | Ни одна модель не дала компилирующийся сервис с первого раза |
| Скорость генерации | Минуты на задачу, но с самопроверкой (сборка, curl) | Секунды на ответ (50 ток/с), но без самопроверки — итерации ложатся на человека |
| Понимание контекста проекта | Сам читает репозиторий, образцы, логи; чинит по регрессии | Видит только то, что вставили в промпт/контекст Continue; правила в SYSTEM соблюдает частично (qwen) или игнорирует (deepseek) |
| Агентный режим | Полный цикл: воспроизвёл → нашёл → починил → прогнал тесты | Отсутствует: только текст → текст; проверка руками |
| Без интернета | ❌ | ✅ полностью офлайн |
| Стоимость | Токены облака | Бесплатно после скачивания (~9 ГБ) |

## Для чего локальной модели хватает

**Хватает** (проверено):
- автокомплит в IDE — 1.5B FIM-модель, мгновенно, офлайн — лучший ROI связки;
- объяснить незнакомый код, набросать чистую функцию/тест/DTO по образцу;
- рутинные правки в одном файле, когда контекст помещается в промпт;
- черновик кода в самолёте/без сети — с последующей ручной доводкой.

**Облако незаменимо**:
- многофайловая генерация, которая должна собраться с первого раза;
- агентный цикл: воспроизведение бага, регрессия, «не сломал ли я остальное»;
- задачи, где важно точное следование правилам проекта (локалки нарушали
  даже при правилах в системном промпте);
- всё, где цена ошибки выше цены токенов.

## Лучшая связка на этом железе (усиление)

`qwen2.5-coder:7b` (t=0.2, top_p=0.9, ctx 16384) для чата/edit +
`qwen2.5-coder:1.5b-base` для автокомплита + `nomic-embed-text` для индекса.
- 7B-кодер обошёл 14B-универсала по качеству кода при вдвое большей скорости —
  специализация бьёт размер;
- deepseek-coder:6.7b — худший в тройке: игнорирует и формат, и правила проекта;
- 14B на 24 GB работает (25 ток/с), но выигрыша не даёт — не стоит своих 9 ГБ
  в этой роли.

## Заметки

- Замер скорости — из Ollama API (`eval_count/eval_duration`), не секундомером.
- Оценка «справилась с первого раза» — компиляцией в песочнице и фокус-тестами
  семантики фикса (`bench/evaluate.py`), не чтением кода на глаз.
- Оба qwen'а «лечили симптом»: убирали краш, но не реализовывали ожидание
  «0 отключает историю» — идеальная иллюстрация разницы между «код без
  исключений» и «код, делающий то, что просили».
